# ProBoxerTimmer 要件定義書

対象は Android・iOS 向けの初版。ボクサーやトレーナーが練習前に時間と回数を決め、練習中は端末から離れていても、残り時間と進行を確認できることを目的とする。

## 基本要件

| 設定項目 | 初期値 | 利用者ができること |
| --- | --- | --- |
| ラウンド時間 | 3分（03:00） | 1ラウンドの長さを変更する |
| インターバル | 30秒（00:30） | ラウンド間の休憩の長さを変更する |
| ラウンド数 | 3 | 練習するラウンドの総数を指定する |

React Native と TypeScript を使用し、両OSで同じ設定と進行ルールを提供する。

## 初版の動作案

1. **開始前**に3項目をまとめて確認・変更できる。ラウンド時間とラウンド数は正の整数（時間は秒単位）、休憩は0秒以上の整数を受け付ける。入力が不正な場合は、該当項目に理由を表示し、修正後に開始できる。
2. **開始**を押すと第1ラウンドの残り時間が減り始める。ラウンドが終わると設定した休憩に入り、休憩が終わると次のラウンドを開始する。休憩が0秒の場合は次のラウンドに直接進む。
3. **一時停止**を押すと、ラウンド中・休憩中のどちらでも残り時間が止まる。再開すると、同じ区間の残り時間から計時を続ける。
4. **最終ラウンド終了**と同時に「練習終了」を表示する。そこから同じ設定で新しい練習を始められる。途中で最初に戻す操作には確認を設け、キャンセルしたら元の計時状態を保つ。

## 画面とゴング

- ラウンド中、休憩中、一時停止中はタイマーを表示し続け、自動ロックを抑止する。練習終了時と設定に戻るときに抑止を解除する。
- 第1ラウンドを含む各ラウンドの開始時と、最終ラウンドを含む各ラウンドの終了時にゴングを1回鳴らす。休憩0秒の場合、同時に起きる終了と開始は1回の合図にまとめる。一時停止と再開には合図を付けない。
- ゴングは常時有効とし、鋭く短い打音を使う。
- 初版では、手動ロックや別アプリへの切り替えでアプリが非アクティブになった時点で計時を一時停止する。戻ったら再開ボタンで続けられる。

## 練習中の表示

| 例（全3ラウンド） | 左上 | 中央の大きな数字 |
| --- | --- | --- |
| 第1ラウンドの途中 | ラウンド 1/3 | 02:41 |
| 第1ラウンド直後の休憩 | 休憩 1/3 | 00:18 |
| 最終ラウンドの途中 | ラウンド 3/3 | 00:09 |

残り時間は赤い7セグメント数字で中央に表示する。横画面を主とし、使用可能な幅と高さに合わせて拡大する。ラウンド中はそのラウンドの残り時間、休憩中は休憩の残り時間を表示する。休憩の設定値を事前に確認できるのは練習設定画面。一時停止・再開・終了の操作は右上のアイコンにまとめ、スクリーンリーダーで各操作名を確認できるようにする。

## 受け入れ条件

以下の同じシナリオを Android と iOS で確認する。計時の例はアプリを前面に表示した状態を前提とする。

| 条件 | 期待する結果 |
| --- | --- |
| 初回設定を開く | ラウンド時間が03:00、休憩が00:30と表示され、両方の時間とラウンド数を変更できる。 |
| 10秒・休憩3秒・2ラウンドで開始する | 10秒経過時に休憩、13秒で第2ラウンド、23秒で練習終了になる。 |
| 1ラウンドを指定する | 第1ラウンドのカウントダウン終了と同時に練習終了になる。 |
| 休憩0秒・2ラウンドを指定する | 第1ラウンド終了時に、そのまま第2ラウンドの設定時間から計時が始まる。 |
| 休憩中に一時停止して5秒待ち、再開する | 停止中は表示とラウンド番号が変わらず、再開後に残っていた休憩時間が経過すると次のラウンドに進む。 |
| ラウンド数に0を入力する | 入力欄に修正理由が表示される。1に直すと開始できる。 |
| 横画面でタイマーを確認する | 赤い7セグメント数字が表示領域を大きく占め、右上の操作アイコンと重ならない。ラウンド中はラウンドの残り時間だけを表示し、休憩に切り替わると休憩の残り時間を表示する。 |
| タイマー画面をグレースケールで確認する | 現在の区間、ラウンドの進み具合、残り時間を文字と数字で読み取れる。 |
| 端末の自動ロック時間より長いラウンド、休憩、一時停止を順に試す | 各状態で操作しなくても画面が点灯し続ける。練習終了後、端末の通常の自動ロックが働く（単体ビルドで確認）。 |
| メディア音量を上げ、10秒・休憩3秒・2ラウンドを開始する | 開始時、10秒、13秒、23秒に鋭く短いゴングが各1回聞こえる。 |
| 休憩中に端末を手動ロックしてからアプリに戻る | 休憩は一時停止状態にあり、再開を押すと残り時間から続く。 |

## 初版の設定範囲

ラウンド時間は1〜5999秒、休憩は0〜5999秒、ラウンド数は1〜99。設定はアプリを開いている間保持する。
