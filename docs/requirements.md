# ProBoxerTimmer 要件定義書

対象は Android・iOS 向けの初版。ボクサーやトレーナーが練習前に時間と回数を決め、練習中は端末から離れていても、残り時間と進行を確認できることを目的とする。

## 基本要件

| 設定項目 | 初期値 | 利用者ができること |
| --- | --- | --- |
| ラウンド時間 | 3分（03:00） | 1秒〜10分の範囲で1ラウンドの長さを選ぶ |
| インターバル | 30秒（00:30） | ラウンド間の休憩の長さを変更する |
| ラウンド数 | 3 | 1〜12回の範囲で練習するラウンドの総数を選ぶ |

React Native と TypeScript を使用し、両OSで同じ設定と進行ルールを提供する。

## 初版の動作案

1. **起動時**はタイマー画面に第1ラウンドの時間を表示し、開始操作を待つ。初回は03:00・休憩30秒・3ラウンドを使い、保存済みの設定があれば復元する。
2. **開始**を押すと第1ラウンドの残り時間が減り始め、その練習の設定3項目を端末に保存する。ラウンドが終わると設定した休憩に入り、休憩が終わると次のラウンドを開始する。休憩が0秒の場合は次のラウンドに直接進む。
3. **一時停止**を押すと、ラウンド中・休憩中のどちらでも残り時間が止まる。再開すると、同じ区間の残り時間から計時を続ける。
4. **リセット**を確認すると、同じ設定で第1ラウンドの開始前に戻る。開始を押すまで残り時間は減らず、開始時にベルが鳴る。**終了**を確認すると「停止」と「00:00」を表示する。確認をキャンセルした場合は元の計時状態を保つ。
5. **最終ラウンド終了**と同時に、タイマー画面に「練習終了」と「00:00」を表示する。再度開始すると同じ設定で第1ラウンドから始まる。
6. **設定**はラウンド表示の左にある歯車から開く。計時中または一時停止中に開く場合は、練習の終了を確認する。時間は分・秒を別々に、ラウンド数は回数をホイールで選ぶ。「初期値にリセット」で3分・休憩30秒・3ラウンドを選択し、「確定」でタイマーに反映する。値を変更した場合は第1ラウンドの開始前を表示する。ラウンド時間が0分0秒の場合は確定できない。

## 画面とゴング

- ラウンド中、休憩中、一時停止中、リセット直後の開始待ちではタイマーを表示し続け、自動ロックを抑止する。練習終了時と設定に戻るときに抑止を解除する。
- 第1ラウンドを含む各ラウンドの開始時と、最終ラウンドを含む各ラウンドの終了時にベルで合図する。休憩0秒の場合、同時に起きる終了と開始は1回の合図にまとめる。一時停止と再開には合図を付けない。
- ベルは常時有効とする。1回の合図に、高く鋭い2打のリングベルを使う。
- 初版では、手動ロックや別アプリへの切り替えでアプリが非アクティブになった時点で計時を一時停止する。戻ったら再開ボタンで続けられる。

## 練習中の表示

| 例（全3ラウンド） | 左上 | 中央の大きな数字 |
| --- | --- | --- |
| 第1ラウンドの途中 | Round 1/3 | 02:41 |
| 第1ラウンド直後の休憩 | 休憩 1/3 | 00:18 |
| 最終ラウンドの途中 | Round 3/3 | 00:09 |
| 練習終了 | 練習終了 | 00:00 |

残り時間は赤い7セグメント数字で中央に表示する。横画面を主とし、使用可能な幅と高さに合わせて拡大する。ラウンド中は左上に「Round 1/3」の形式で、太く読みやすくラウンド番号を表示する。ラウンド中はそのラウンドの残り時間、休憩中は休憩の残り時間を表示する。休憩の設定値を事前に確認できるのは練習設定画面。右上に一時停止・再開、リセット、終了の順でアイコンを並べ、誤操作を避けるため間隔を空ける。スクリーンリーダーで各操作名を確認できるようにする。

## 受け入れ条件

以下の同じシナリオを Android と iOS で確認する。計時の例はアプリを前面に表示した状態を前提とする。

| 条件 | 期待する結果 |
| --- | --- |
| 保存済みの設定がない状態でアプリを起動する | タイマー画面に「Round 1/3」と「03:00」が表示される。歯車を押すと休憩30秒を含む初期値を確認できる。 |
| ラウンド時間の分を10に合わせ、回数を上限まで回す | 秒は00に揃い、ラウンド数は12回で止まる。休憩の範囲は0秒〜99分59秒。 |
| 設定3項目を変更して練習を開始し、アプリを終了して起動し直す | タイマーに設定したラウンド時間と総ラウンド数が出る。歯車を押すと最後に開始した練習の設定3項目を確認できる。 |
| ラウンド時間の分と秒を順に変更し、ラウンド数も変更する | 各ホイールが中央に揃い、「確定」で選んだ値をタイマーに反映できる。 |
| ホイールの値を変更して「初期値にリセット」を押す | 設定画面のまま3分・休憩30秒・3ラウンドが中央に揃う。「確定」でタイマーに反映する。 |
| 10秒・休憩3秒・2ラウンドで開始する | 10秒経過時に休憩、13秒で第2ラウンド、23秒で練習終了になる。 |
| 1ラウンドを指定する | 第1ラウンドの終了後もタイマー画面で「練習終了」と「00:00」が表示され続ける。 |
| 休憩0秒・2ラウンドを指定する | 第1ラウンド終了時に、そのまま第2ラウンドの設定時間から計時が始まる。 |
| 休憩中に一時停止して5秒待ち、再開する | 停止中は表示とラウンド番号が変わらず、再開後に残っていた休憩時間が経過すると次のラウンドに進む。 |
| ラウンド時間を0分0秒に合わせる | 理由が表示され、設定を反映できない。0分1秒に変えると設定を反映できる。 |
| 第2ラウンドや休憩中にリセットする | 確認後、第1ラウンドの開始前に戻り、設定されたラウンド時間を表示する。開始するとゴングが鳴り、計時が始まる。 |
| リセットの確認をキャンセルする | 計時中なら進行を続け、一時停止中なら残り時間を保つ。 |
| 横画面でタイマーを確認する | 赤い7セグメント数字が表示領域を大きく占め、右上の操作アイコンと重ならない。ラウンド中はラウンドの残り時間だけを表示し、休憩に切り替わると休憩の残り時間を表示する。 |
| タイマー画面をグレースケールで確認する | 現在の区間、ラウンドの進み具合、残り時間を文字と数字で読み取れる。 |
| 端末の自動ロック時間より長いラウンド、休憩、一時停止を順に試す | 各状態で操作しなくても画面が点灯し続ける。練習終了後、端末の通常の自動ロックが働く（単体ビルドで確認）。 |
| メディア音量を上げ、10秒・休憩3秒・2ラウンドを開始する | 開始時、10秒、13秒、23秒に2打のリングベルが1組ずつ聞こえる。 |
| 休憩中に端末を手動ロックしてからアプリに戻る | 休憩は一時停止状態にあり、再開を押すと残り時間から続く。 |

## 初版の設定範囲

ラウンド時間は1秒〜10分。10分を選ぶと秒ホイールは00に固定する。休憩時間は0秒〜99分59秒、ラウンド数は1〜12回。

次回起動時には、最後に開始した練習のラウンド時間・休憩時間・ラウンド数を端末から読み込み、最初のタイマー画面に反映する。保存済みの項目がない場合は初期値を使う。
