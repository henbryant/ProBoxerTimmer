# ProBoxerTimmer 要件定義書

Android・iOS 向けのボクシング用ラウンドタイマー。ボクサーやトレーナーが練習前に時間と回数を決め、練習中は端末から離れていても、残り時間と進行を確認できることを目的とする。初回のストア公開は iOS に限る。

## 基本要件

| 設定項目 | 初期値 | 利用者ができること |
| --- | --- | --- |
| ラウンド時間 | 3分（03:00） | 1秒〜10分の範囲で1ラウンドの長さを選ぶ |
| インターバル | 30秒（00:30） | 0秒〜99分59秒の範囲でラウンド間の休憩時間を選ぶ |
| ラウンド数 | 3 | 1〜12回の範囲で練習するラウンドの総数を選ぶ |

Expo、React Native、TypeScript を使用し、両OSで同じ設定と進行ルールを提供する。ラウンド時間を10分にすると、秒のホイールは00に固定する。

## タイマーと設定の動作

1. **起動時**はタイマー画面に第1ラウンドの時間を表示し、開始操作を待つ。初回は03:00・休憩30秒・3ラウンドを使い、保存済みの設定があれば復元する。
2. **開始**を押すと第1ラウンドの残り時間が減り始め、その練習の設定3項目を端末に保存する。ラウンドが終わると設定した休憩に入り、休憩が終わると次のラウンドを開始する。休憩が0秒の場合は次のラウンドに直接進む。
3. **一時停止**を押すと、ラウンド中・休憩中のどちらでも残り時間が止まる。再開すると、同じ区間の残り時間から計時を続ける。
4. **リセット**を確認すると、同じ設定で第1ラウンドの開始前に戻る。開始を押すまで残り時間は減らず、開始時にベルが鳴る。**終了**を確認すると「停止」と「00:00」を表示する。確認をキャンセルした場合は元の計時状態を保つ。
5. **最終ラウンド終了**と同時に、タイマー画面に「練習終了」と「00:00」を表示する。再度開始すると同じ設定で第1ラウンドから始まる。
6. **設定**はラウンド表示の左にある歯車から開く。計時中または一時停止中に開く場合は、練習の終了を確認する。ラウンド時間とインターバルは分・秒を別々に、ラウンド数は回数をホイールで選ぶ。「初期値にリセット」で3分・休憩30秒・3ラウンドを選択し、「確定」でタイマーに反映する。値を変更した場合は第1ラウンドの開始前を表示する。ラウンド時間が0分0秒の場合は確定できない。確定前に設定画面から戻ると、編集中の値を破棄する。

## 端末内のデータ

練習を開始するたびに、ラウンド時間・インターバル・ラウンド数を端末内に保存し、前回分を上書きする。保存した3項目は次回の起動時に復元する。練習の途中経過や履歴は保存しない。設定の読み込みに失敗した場合は初期値を使い、読み込みや保存に失敗したことを画面に表示する。

## 画面とゴング

- ラウンド中、休憩中、一時停止中、リセット直後の開始待ちでは、端末の自動ロックを抑止する。起動直後の開始待ち、手動または最終ラウンドでの終了後、設定画面では端末の通常の自動ロックが働く。
- 第1ラウンドを含む各ラウンドの開始時と、最終ラウンドを含む各ラウンドの終了時にベルで合図する。休憩0秒の場合、同時に起きる終了と開始は1回の合図にまとめる。一時停止と再開には合図を付けない。
- ゴングは常時有効とし、1回の合図に、高く鋭い2打のリングベルを使う。音声ファイルはアプリに同梱する。
- 手動ロックや別アプリへの切り替えでアプリが非アクティブになった時点で計時を一時停止する。戻ったら再開ボタンで続けられる。

## 練習中の表示

| 例（全3ラウンド） | 左上 | 中央の大きな数字 |
| --- | --- | --- |
| 第1ラウンドの途中 | Round 1/3 | 02:41 |
| 第1ラウンド直後の休憩 | 休憩 1/3 | 00:18 |
| 最終ラウンドの途中 | Round 3/3 | 00:09 |
| 練習終了 | 練習終了 | 00:00 |

残り時間は赤い7セグメント数字で中央に表示する。専用フォントの読み込み前や読み込めない場合は標準フォントを使う。縦・横それぞれで表示領域に合わせて文字サイズを調整し、横画面では高さに余裕があれば数字を縦方向に拡大する。ラウンド中はそのラウンドの残り時間、休憩中は休憩の残り時間を表示する。設定したインターバルは練習前に設定画面で確認できる。

左上には現在の区間と進行を表示する。一時停止中は区間表示の下に「一時停止」を表示する。右上に左から終了、リセット、開始・一時停止・再開を切り替えるアイコンの順で間隔を空けて並べる。練習終了後は「もう一度開始」の操作を表示する。スクリーンリーダーで各操作の名前と設定ホイールの選択値を確認できるようにする。

設定画面では、「初期値にリセット」と「確定」を画面下部に固定し、見出しとの間に設定ホイールを縦方向に中央揃えで配置する。スクロールは各ホイール内で行う。高さが足りない場合はホイールの表示範囲を縮め、選択中の値を中央に保つ。ホイールとボタンの操作領域を確保するため、設定画面の文字の拡大率には画面の高さに応じた上限を設ける。「夢は必ず実現する事」は、横画面でのみ、44ptの衡山毛筆フォントで画面上部の中央に表示する。幅の広い横画面では「設定」と同じ行に並べる。

## 受け入れ条件

以下のシナリオを Android と iOS で確認する。計時の例はアプリを前面に表示した状態を前提とする。計時とゴングを鳴らすタイミングの判定、保存値の復元、文字サイズの計算は `npm test` でも確認する。

| 条件 | 期待する結果 |
| --- | --- |
| 保存済みの設定がない状態でアプリを起動する | タイマー画面に「Round 1/3」と「03:00」が表示される。歯車を押すと休憩30秒を含む初期値を確認できる。 |
| ラウンド時間の分を10に合わせ、回数を上限まで回す | 秒は00に揃い、ラウンド数は12回で止まる。休憩の範囲は0秒〜99分59秒。 |
| 設定3項目を変更して練習を開始し、アプリを終了して起動し直す | タイマーに設定したラウンド時間と総ラウンド数が出る。歯車を押すと最後に開始した練習の設定3項目を確認できる。 |
| 練習を開始して設定を保存した後、別の値を確定し、練習を開始せずにアプリを起動し直す | 最後に開始した練習の設定が復元される。 |
| ラウンド時間の分と秒を順に変更し、ラウンド数も変更する | 各ホイールが中央に揃い、「確定」で選んだ値をタイマーに反映できる。 |
| 高さの限られた縦画面で設定ホイールを操作する | 選択中の値が各ホイールの中央に表示され、「初期値にリセット」と「確定」は画面下部に固定される。 |
| ホイールの値を変更して「初期値にリセット」を押す | 設定画面のまま3分・休憩30秒・3ラウンドが中央に揃う。「確定」でタイマーに反映する。 |
| 10秒・休憩3秒・2ラウンドで開始する | 10秒経過時に休憩、13秒で第2ラウンド、23秒で練習終了になる。 |
| 1ラウンドを指定する | 第1ラウンドの終了後もタイマー画面で「練習終了」と「00:00」が表示され続ける。 |
| 休憩0秒・2ラウンドを指定する | 第1ラウンド終了時に、そのまま第2ラウンドの設定時間から計時が始まる。 |
| 休憩中に一時停止して5秒待ち、再開する | 停止中は表示とラウンド番号が変わらず、再開後に残っていた休憩時間が経過すると次のラウンドに進む。 |
| ラウンド時間を0分0秒に合わせる | 理由が表示され、設定を反映できない。0分1秒に変えると設定を反映できる。 |
| 第2ラウンドや休憩中にリセットする | 確認後、第1ラウンドの開始前に戻り、設定されたラウンド時間を表示する。開始するとゴングが鳴り、計時が始まる。 |
| リセットの確認をキャンセルする | 計時中なら進行を続け、一時停止中なら残り時間を保つ。 |
| 横画面でタイマーを確認する | 赤い7セグメント数字が表示領域を大きく占め、右上の操作アイコンと重ならない。ラウンド中はラウンドの残り時間だけを表示し、休憩に切り替わると休憩の残り時間を表示する。 |
| タイマー画面をグレースケールで確認する | 現在の区間、ラウンドの進み具合、残り時間を文字と数字で読み取れる。 |
| 端末の自動ロック時間より長いラウンド、休憩、一時停止を順に試す | 各状態で操作しなくても画面が点灯し続ける。練習終了後、端末の通常の自動ロックが働く（単体ビルドで確認）。 |
| メディア音量を上げ、10秒・休憩3秒・2ラウンドを開始する | 開始時、10秒、13秒、23秒に2打のリングベルが1組ずつ聞こえる。 |
| 休憩中に端末を手動ロックしてからアプリに戻る | 休憩は一時停止状態にあり、再開を押すと残り時間から続く。 |

## iOS の初回配布

- [app.json](../app.json) の iOS Bundle ID は `com.henbryant.proboxertimmer`。iOS アイコンには白背景・透過なしの [1024 × 1024 px の PNG](../assets/ios-icon.png) を使用する。
- [eas.json](../eas.json) の `production` プロファイルで iOS の配布用ビルドを作る。ビルド番号は EAS で管理し、配布用ビルドごとに自動採番する。ストアに表示するバージョンは `app.json` の `version` で管理する。

### 初回提出までの作業

1. [プライバシーポリシー](privacy-policy.md) と [サポートページ](support.md) を公開する。アプリの設定画面からプライバシーポリシーを開けるようにし、リンク先を確認する。 [App Review ガイドライン](https://developer.apple.com/app-store/review/guidelines/#privacy)
2. Apple Developer Program のメンバーシップを有効にし、App Store Connect に同じ Bundle ID で iOS アプリを登録する。EAS で配布用ビルドを作成し、App Store Connect にアップロードする。 [Expo の iOS 提出手順](https://docs.expo.dev/submit/ios/)
3. TestFlight で iPhone にインストールし、縦・横画面、タイマー、ゴング、設定の保存、プライバシーポリシーへの遷移を確認する。App Store Connect にプライバシーポリシーとサポートページの URL を登録し、掲載情報、iPhone のスクリーンショット、年齢制限、プライバシー申告を揃えて App Review に提出する。
