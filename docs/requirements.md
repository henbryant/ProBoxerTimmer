# ProBoxerTimmer 要件定義書

対象は Android・iOS 向けの初版。ボクサーやトレーナーが練習前に時間と回数を決め、練習中は端末から離れていても、残り時間と進行を確認できることを目的とする。

## 基本要件

| 設定項目 | 初期値 | 利用者ができること |
| --- | --- | --- |
| ラウンド時間 | 3分（03:00） | 1ラウンドの長さを変更する |
| インターバル | 30秒（00:30） | ラウンド間の休憩の長さを変更する |
| ラウンド数 | 未決定 | 練習するラウンドの総数を指定する |

React Native と TypeScript を使用し、両OSで同じ設定と進行ルールを提供する。

## 初版の動作案

1. **開始前**に3項目をまとめて確認・変更できる。ラウンド時間とラウンド数は正の整数（時間は秒単位）、休憩は0秒以上の整数を受け付ける。入力が不正な場合は、該当項目に理由を表示し、修正後に開始できる。
2. **開始**を押すと第1ラウンドの残り時間が減り始める。ラウンドが終わると設定した休憩に入り、休憩が終わると次のラウンドを開始する。休憩が0秒の場合は次のラウンドに直接進む。
3. **一時停止**を押すと、ラウンド中・休憩中のどちらでも残り時間が止まる。再開すると、同じ区間の残り時間から計時を続ける。
4. **最終ラウンド終了**と同時に「練習終了」を表示する。そこから同じ設定で新しい練習を始められる。途中で最初に戻す操作には確認を設け、キャンセルしたら元の計時状態を保つ。

## 練習中の表示

| 例（全3ラウンド） | 画面上部 | 中央の大きな数字 | 次の予定 |
| --- | --- | --- | --- |
| 第1ラウンドの途中 | ラウンド 1/3 | 02:41 | 次は休憩 00:30 |
| 第1ラウンド直後の休憩 | 休憩 · 1/3 完了 | 00:18 | 次はラウンド 2/3 |
| 最終ラウンドの途中 | ラウンド 3/3 | 00:09 | 次は練習終了 |

据え置きタイマーを参考に、背景は落ち着いた単色とし、残り時間には太くコントラストの高い数字を使う。桁幅を固定し、毎秒表示が動いて見えるのを防ぐ。現在の区間と次の予定は既存アプリの参考画像から取り入れ、色を見分けなくても文字で判別できるようにする。操作ボタンは数字に重ならない位置に置く。

## 受け入れ条件

以下の同じシナリオを Android と iOS で確認する。計時の例はアプリを前面に表示した状態を前提とする。

| 条件 | 期待する結果 |
| --- | --- |
| 初回設定を開く | ラウンド時間が03:00、休憩が00:30と表示され、両方の時間とラウンド数を変更できる。 |
| 10秒・休憩3秒・2ラウンドで開始する | 10秒経過時に休憩、13秒で第2ラウンド、23秒で練習終了になる。 |
| 1ラウンドを指定する | 第1ラウンドのカウントダウン終了と同時に練習終了になる。 |
| 休憩0秒・2ラウンドを指定する | 第1ラウンド終了時に、そのまま第2ラウンドの設定時間から計時が始まる。 |
| 休憩中に一時停止して5秒待ち、再開する | 停止中は表示とラウンド番号が変わらず、再開後に残っていた休憩時間が経過すると次のラウンドに進む。 |
| ラウンド数に0を入力する | 入力欄に修正理由が表示される。1に直すと開始できる。 |
| タイマー画面をグレースケールで確認する | 練習中と休憩中のどちらでも、残り時間・ラウンドの進み具合・次の予定を文字と数字から読み取れる。 |

## 実装前に決めること

- 初回のラウンド数、各設定の上限、前回の設定を次回に引き継ぐか。
- 切り替わりを知らせるゴング音・振動の有無と、消音時の扱い。
- 練習中の画面の自動消灯を防ぐか。手動で画面をロックしたときや別アプリに切り替えたとき、計時と合図をどう扱うか。
