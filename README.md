# ProBoxerTimmer

ボクシングの練習中に、離れた位置からでも残り時間がひと目で分かるラウンドタイマーです。React Native と TypeScript を使い、Android と iOS 向けに開発します。

## 練習の流れ

ラウンド時間（初期値 **3分**）、インターバル（初期値 **30秒**）、ラウンド数（初期値 **3**）を設定して開始します。ラウンドと休憩は自動で切り替わります。たとえば2ラウンドなら「3分の練習 → 30秒の休憩 → 3分の練習」で終了します。

## タイマー画面

ジムの据え置きタイマーのように、残り時間を画面中央に最も大きく表示します。その上下に「ラウンド 1/3」「次は休憩 00:30」などを表示し、練習中に設定画面を開かなくても進行を確認できるようにします。

タイマー表示中は端末の自動消灯を防ぎます。各ラウンドの開始・終了をゴング音で知らせます。音は設定画面でも練習中でも切り替えられます。

## ローカルで起動

Expo SDK 58 と React Native を使用します。Node.js 24 LTS（24.3 以上）と npm を用意し、リポジトリ直下で実行してください。

```sh
npm ci
npm start
```

開発サーバーの QR コードを SDK 58 対応の Expo Go で読み取ります。Android エミュレーターを使用する場合はターミナルで `a`、Mac に Xcode と iOS Simulator を用意した場合は `i` で起動できます。

## 確認方法

```sh
npm run typecheck

```
