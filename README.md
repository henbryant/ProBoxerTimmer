# ProBoxerTimmer

ボクシングの練習中に、離れた位置からでも残り時間がひと目で分かるラウンドタイマーです。React Native と TypeScript を使い、Android と iOS 向けに開発します。

## 練習の流れ

ラウンド時間（初期値 **3分**）とインターバル（初期値 **30秒**）は、分と秒を別々のホイールで選びます。ラウンド数（初期値 **3**）もホイールで選べます。ラウンドと休憩は自動で切り替わります。たとえば2ラウンドなら「3分の練習 → 30秒の休憩 → 3分の練習」で終了します。

## タイマー画面

横画面では、残り時間を赤い7セグメント数字で画面いっぱいに表示します。現在の区間とラウンド番号は左上に、一時停止・再開、リセット、終了のアイコンは右上にあります。リセットを確認すると、同じ設定のまま第1ラウンドの開始前に戻ります。休憩に入ると、中央の数字が休憩の残り時間に切り替わります。

タイマー表示中は端末の自動消灯を防ぎます。各ラウンドの開始・終了を鋭く短いゴング音で知らせます。

## ローカルで起動

Expo SDK 58 と React Native を使用します。Node.js 24 LTS（24.3 以上）と npm を用意し、リポジトリ直下で実行してください。

```sh
npm ci
npm start
```

開発サーバーの QR コードを SDK 58 対応の Expo Go で読み取ります。Android エミュレーターを使用する場合はターミナルで `a`、Mac に Xcode と iOS Simulator を用意した場合は `i` で起動できます。

## 確認方法

