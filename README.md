# ProBoxerTimmer

ボクシングの練習中に、離れた位置からでも残り時間がひと目で分かるラウンドタイマーです。React Native と TypeScript を使い、Android と iOS 向けに開発します。

## 練習の流れ

ラウンド時間（初期値 **3分**）、インターバル（初期値 **30秒**）、ラウンド数を設定して開始します。ラウンドと休憩は自動で切り替わります。たとえば2ラウンドなら「3分の練習 → 30秒の休憩 → 3分の練習」で終了します。

## タイマー画面

ジムの据え置きタイマーのように、残り時間を画面中央に最も大きく表示します。その上下に「ラウンド 1/3」「次は休憩 00:30」などを表示し、練習中に設定画面を開かなくても進行を確認できるようにします。
